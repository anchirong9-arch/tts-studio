이 화면은 음성 합성을 내 PC에서 합니다. 아래 3단계만 한 번 해 두면 계속 쓸 수 있어요.

  1. ZIP 내려받기 → 압축 풀기
  2. 폴더 안의 실행하기.bat 더블클릭
  3. 자동으로 열리는 http://127.0.0.1:8765 창에서 사용
⬇ ZIP 다운로드 로컬 스튜디오 열기

서버 없이도 예상 길이 계산과 예상 자막(.srt)은 그대로 쓸 수 있습니다. 브라우저 미리듣기도 됩니다.

    ⚙️ 처음 한 번만 — 내 PC에서 서버 켜기펼치기
    1. ZIP 내려받기

      아래 버튼으로 tts-studio 폴더를 받아 압축을 풉니다. (원하는 위치 아무 곳이나 OK)

      ⬇ tts-studio.zip
    2. 실행하기.bat 더블클릭

      처음 한 번은 자동으로 필요한 패키지(edge-tts)를 설치합니다. 1~2분 걸리고, 그다음부터는 바로 켜집니다. 검은 창은 켜 둔 채로 사용하세요.

    3. 브라우저가 자동으로 열립니다

      http://127.0.0.1:8765 창에서 작업하면 됩니다. 이 GitHub 화면에서도 서버만 켜져 있으면 그대로 쓸 수 있어요.

    Python이 없다고 나오면 python.org에서 설치하세요. 설치 첫 화면의 “Add python.exe to PATH”를 꼭 체크하세요.
