# 🎙️ TTS 스튜디오

쇼츠 대본을 넣으면 **한국어 음성(MP3)** 과 **자막(.srt)** 을 한 번에 뽑는 도구입니다.
음성 합성은 내 PC에서 돌아가고(무료 · 무제한), 웹 화면은 GitHub Pages에서 열립니다.

- 웹 UI: <https://anchirong9-arch.github.io/tts-studio/>
- 내려받기: [tts-studio.zip](https://github.com/anchirong9-arch/tts-studio/archive/refs/heads/main.zip)

## 쓰는 법 (처음 한 번만)

1. 위 ZIP을 받아 **압축을 풉니다.** (예: `C:\tts-studio`)
2. 폴더 안의 **`실행하기.bat`** 을 더블클릭합니다.
   (이름이 깨졌다면 `run.bat` 도 같은 기능입니다.)
3. 처음 한 번은 자동으로 필요한 패키지를 설치합니다. 1~2분 뒤 브라우저가 `http://127.0.0.1:8765` 로 열립니다.
4. 그 창에서 대본을 넣고 **음성 생성** → **MP3 저장 / .srt 자막** 을 누르면 끝.

> 검은 창(서버)은 쓰는 동안 **켜 두세요.** 닫으면 음성 생성이 멈춥니다.
> Python 3.9 이상이 필요합니다. Python이 없다고 나오면 [python.org](https://www.python.org/downloads/windows/)에서 설치하고, 설치 첫 화면의 **“Add python.exe to PATH”** 를 꼭 체크하세요.

## 기능

| 기능 | 설명 |
| --- | --- |
| 목소리 6종 | **인준**(남·차분), **선희**(여·밝음), **현수**(남·부드러움), **앤드루**(영·깊은 톤), **에이바**(영·밝은 톤), **번역기**(구글 번역기 기계음) — 각 카드의 ▶ 로 미리듣기 |
| 요즘 쇼츠 메타 12종 | 누르면 목소리·속도·피치가 한 번에 세팅 (아래 표) |
| 속도 | `-30%` ~ `+50%` (1% 단위) |
| 피치 | `-30Hz` ~ `+60Hz` (1Hz 단위) |
| 예상 영상 길이 | 대본을 넣는 즉시 초 단위로 표시, **15·30·60초 쇼츠 길이 판정**까지 |
| 자막 .srt | 실제 음성의 **단어 타이밍**으로 자막 생성 · 미리보기 · 복사 · 다운로드 |
| 자막 분할 | 자동(문장 + 길면 나눔) / 줄바꿈 기준 / 마침표·쉼표 기준 |
| MP3 저장 | `tts-YYYYMMDD-HHMM.mp3` |
| 오프라인 보조 | 서버가 꺼져 있어도 예상 길이·예상 자막·브라우저 미리듣기 사용 가능 |

### 요즘 쇼츠 메타 프리셋

| 프리셋 | 세팅 | 쓰는 곳 |
| --- | --- | --- |
| 🔥 캡컷 텐션 남 | 인준 +25% / +12Hz | "저 됐어요!" "큰일 났어요 여러분" 자극 훅 |
| 🔥 캡컷 텐션 여 | 선희 +30% / +10Hz | 리액션·언박싱·정보 훅 |
| 😤 킹받는 하이톤 | 선희 +12% / +50Hz | 초딩·어그로·킹받는 짤 |
| 📖 썰·레딧 스토리 | 인준 +8% / 0Hz | 사연·썰툰 내레이션 |
| 📰 뉴스 브리핑 | 인준 +5% / -2Hz | 사건·이슈 정리 |
| 🎬 다큐·감성 | 현수 -12% / -3Hz | 새벽 감성 내레이션 |
| 👴 묵직한 아저씨 | 인준 -12% / -20Hz | 해설·고민 상담 톤 |
| 😌 ASMR 속삭임 | 선희 -20% / -5Hz | 수면·집중 콘텐츠 |
| 🛒 리뷰·꿀팁 친근 | 선희 +5% / +2Hz | 제품 리뷰·정보 전달 |
| 🎮 게임 아나운서 | 인준 +35% / +8Hz | 하이라이트·스포츠 |
| 🇺🇸 영어 밈 내레이션 | 앤드루 +10% / 0Hz | 영어 대본·해외 밈 |
| 🤖 번역기 기계음 | 번역기(gTTS) | 킹받는 구글 번역기 짤 |

속도·피치를 직접 만지면 프리셋 표시가 **직접 설정**으로 바뀝니다. 마음에 드는 조합은 그대로 두고 대본만 갈아 끼우면 됩니다.

자막은 음성을 만들 때 edge-tts가 보내 주는 **단어별 타임코드**를 그대로 써서 맞춥니다. (서버 없이 만든 자막과 번역기 음성은 글자 수·실제 오디오 길이로 추정)

### 목소리 참고

- edge-tts 한국어 화자는 지금 **인준·선희·현수 3종만 살아 있습니다.** (JiMin·SeoHyeon·SoonBok·YuJin·BongJin·GookMin 은 목록에서 내려가 합성이 안 됩니다)
- 앤드루·에이바는 영어 화자지만 한국어 대본도 읽습니다. 영어 억양이 섞여 **외국인 한국어** 느낌이 나서 밈에 쓸 수 있습니다.
- 번역기(gTTS)는 구글 번역기 서버를 쓰는 별도 엔진입니다. 속도를 `-10%` 아래로 내리면 천천히 읽고, 피치는 고정입니다. 문장마다 요청이 나가서 **1,500자까지** 지원합니다.
- `gTTS` 설치가 안 된 PC라면 나머지 목소리는 그대로 되고, 번역기 카드에 **설치 필요** 표시가 뜹니다. `실행하기.bat` 을 다시 실행하면 설치됩니다.

## 파일 구성

```
tts-studio/
├─ index.html          웹 UI
├─ style.css           다크 스튜디오 테마
├─ app.js              대본·설정·자막(SRT) 로직
├─ server.py           로컬 서버 (정적 파일 + /health + /tts)
├─ requirements.txt    edge-tts · gTTS
├─ 실행하기.bat        1클릭 실행기 (Windows)
├─ run.bat             같은 실행기 (영문 파일명)
└─ README.md
```

## 로컬 서버 API

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/health` | 상태·버전·목소리 목록 JSON |
| POST | `/tts` | `{text, voice, rate, pitch}` → `audio/mpeg` |
| POST | `/tts?format=json` | 같은 요청 → `{audio_base64, duration_ms, words[]}` (자막 타이밍용) |

`voice` 값: `ko-KR-InJoonNeural` · `ko-KR-SunHiNeural` · `ko-KR-HyunsuMultilingualNeural` · `en-US-AndrewMultilingualNeural` · `en-US-AvaMultilingualNeural` · `gtts-ko`

```bash
curl -X POST http://127.0.0.1:8765/tts \
  -H "Content-Type: application/json" \
  -d '{"text":"안녕하세요","voice":"ko-KR-SunHiNeural","rate":"+30%","pitch":"+10Hz"}' \
  -o test.mp3
```

옵션: `python server.py --port 9000 --no-open`

## 문제 해결

- **“서버 꺼짐”으로 보여요** → `실행하기.bat` 창이 켜져 있는지 확인하고 웹 화면의 **연결 확인**을 누르세요.
- **번역기 카드에 “설치 필요”** → `실행하기.bat` 을 다시 실행하면 gTTS 가 설치됩니다. (다른 목소리는 그대로 사용 가능)
- **번역기 음성만 실패** → 구글 번역기 서버가 막힌 경우입니다. 다른 목소리를 쓰거나 잠시 뒤 다시 시도하세요.
- **Python 3.8 이하라고 나와요** → 3.9 이상을 설치해 주세요.
- **`pip install` 실패** → 인터넷 연결/방화벽 확인. 사내망이면 집 네트워크에서 시도해 보세요.
- **소리가 안 나요** → 브라우저 탭이 음소거되지 않았는지, 출력 장치를 확인하세요.
- **글자가 깨져 보여요** → Windows 10 이상 + 최신 브라우저(Chrome/Edge) 권장.

## 만든 방식

[edge-tts](https://github.com/rany2/edge-tts) (Microsoft Edge 읽기 음성) 와 [gTTS](https://github.com/pndurette/gTTS) (구글 번역기 음성) 를 파이썬 표준 `http.server` 로 감싼 구조입니다.
인터넷이 필요하고, 개인 사용 범위에서 쓰세요.
